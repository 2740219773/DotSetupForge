### 关键技术坑（记住！）
- **WPF 项目的 wpftmp 临时编译项目不继承 ImplicitUsings** → UI 项目所有文件必须显式 `using System.IO;`（File/Path/Directory 等）
- EditableProject 的属性名（SourceType/RuntimeFamily/InstallScope）与 Core 枚举重名 → 内部必须全限定 `DotSetupForge.Core.Models.SourceType.Project`
- `[ObservableProperty]` 的 partial OnXxxChanged 只在源生成属性上可用，手写属性没有
- WPF RelayCommand<T> 的 CommandParameter 传字符串不会自动转枚举 → XAML 用 `{x:Static vm:PageKind.XXX}`
